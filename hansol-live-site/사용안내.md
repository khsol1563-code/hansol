# 고한솔 공개 웹앱

방문자는 회원가입이나 로그인 없이 소개, 프로젝트, 연락처를 볼 수 있습니다.
휴대폰 번호를 삭제하고, 첫 화면에 귀여운 20대 남성 캐릭터 일러스트를 추가했습니다.
모바일 하단 탐색 메뉴와 홈 화면 추가용 웹앱 설정을 포함합니다.

관리자 편집창만 비밀번호 12345로 보호합니다.
소개, 경력, 학력, 수상, 이메일을 수정하고 서버에 저장합니다.
저장 후 새로 접속하거나 새로고침한 방문자에게도 수정 내용이 반영됩니다.
비밀번호 검사는 서버에서 수행하며 로그인 세션은 12시간 뒤 만료됩니다.
12345는 추측하기 쉬우므로 운영 시 더 긴 비밀번호를 권장합니다.
